moga shader viewer

Paste the full output of an example (for example example_pbr.exe), then press Render. The page splits it into GLSL vertex, GLSL fragment and WGSL, fills uniforms, textures and tables from the reflected layout, and draws a lit sphere with each backend. A program without a view projection matrix gets a clip space triangle.
